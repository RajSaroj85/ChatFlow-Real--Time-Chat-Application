# 💬 Real-Time Chat Application

A modern and responsive **Real-Time Chat Application** designed to make communication fast, smooth, and seamless. The application allows users to connect with each other through instant messaging, with support for one-to-one conversations, group chats, and live message updates.


liveweb:-- https://chat-flow-real-time-chat-applicatio-nine.vercel.app/

## 🚀 Features

- **One-to-One Chat:** Communicate privately with other users.
- **Group Chat Support:** Create group conversations and chat with multiple users.
- **Real-Time Messaging:** Send and receive messages instantly.
- **Online/Offline Status:** View users' availability and activity status.
- **Chat History:** Access previous conversations and messages.
- **Responsive UI:** Enjoy a smooth experience across desktop, tablet, and mobile devices.
- **User-Friendly Interface:** Simple, clean, and intuitive design.
- **Fast & Reliable Messaging:** Seamless communication with real-time updates.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Language:** TypeScript
- **Styling:** CSS
- **Icons:** Lucide React

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd Real-Time-Chat-Application
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in browser**

```text
http://localhost:5173
```
